# Kordon Online: Border Queues

### Conozca la cola antes de llegar a la frontera.

Kordon Online muestra las colas y los tiempos de espera en directo en los pasos fronterizos de Ucrania, para que elija el mejor paso y planifique su viaje con confianza. Claro, rápido y pensado para viajes reales.

## Descargar

[![play](https://img.shields.io/badge/Google_Play-Download-34A853?style=for-the-badge&logo=googleplay&logoColor=white)](https://play.google.com/store/apps/details?id=online.kordon.app) [![ios](https://img.shields.io/badge/App_Store-Download-0D96F6?style=for-the-badge&logo=apple&logoColor=white)](https://apps.apple.com/app/kordon-online-border-queues/id6792260937)

## Funciones

- **Colas y tiempos de espera en directo** en los pasos fronterizos de Ucrania
- **Previsión del tiempo de espera** para elegir el mejor momento
- **Resumen de reseñas** de otros viajeros sobre cada paso
- **Mapa con filtros y puntos de interés** en el camino
- **Ranking de autobuses** para comparar servicios
- **Notificaciones** para no tener que estar pendiente
- **App para Apple Watch**: la cola en su muñeca
- **Tema oscuro** para un uso cómodo de noche
