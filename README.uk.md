# Kordon Online: Border Queues

### Дізнайтеся про чергу ще до того, як доїдете до кордону.

Kordon Online показує актуальні черги та час очікування на пунктах пропуску України, щоб ви могли обрати найкращий перехід і впевнено спланувати поїздку. Зрозуміло, швидко й створено для реальних подорожей.

## Можливості

- **Актуальні черги та час очікування** на пунктах пропуску України
- **Прогноз часу очікування**, щоб обрати слушний момент для поїздки
- **Підсумок відгуків** про пункти пропуску від інших мандрівників
- **Мапа з фільтрами та цікавими місцями** на шляху
- **Рейтинг автобусів** для порівняння рейсів
- **Сповіщення**, щоб не потрібно було постійно перевіряти
- **Застосунок для Apple Watch** — черга на вашому зап'ясті
- **Темна тема** для зручного користування вночі
